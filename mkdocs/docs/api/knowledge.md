# Knowledge & beliefs

What a character *thinks is true* about the world — a small bag of beliefs that
shapes how an agent reasons and what it can perceive. This is kept separate from
the world graph, which stays the single source of truth: a belief is context, not
authority, and only actions through the precondition gate ever change the world.
