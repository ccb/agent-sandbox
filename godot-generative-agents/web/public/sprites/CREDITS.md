# Sprite credit

`player.png` is the **Player** sheet from the **Cute Fantasy (Free)** pack by
**Kenmi** — a 6×10 grid of 32×32 frames. It is the exact sheet the Godot replay
animates on the campus map (`godot-generative-agents/Cute_Fantasy_Free/Player/Player.png`,
wired into `scripts/penn_replay.gd`); a copy lives here so the React agent card can
show each agent's on-map sprite (frame 0, the front-facing idle pose) as a portrait,
tinted per persona to match the canvas.
