# RunStore — SQLite + JSONL Persistence for Live Runs (#304)

**Issue:** #304 · **Branch:** `feat/run-store-304` off `godot-ga-main` ·
**Review track:** godot-ga-main. (The issue header says "target `main`", but it
predates #399 — `backend` now lives under `godot-generative-agents/`, and this
change is backend + tests only.)

## Goal

A run is ephemeral today: the bake dumps everything into `penn_replay.json` at
the end and discards state; a live run vanishes with the process. This ships
the `RunStore` — durable run metadata + per-step frames + queryable agent
memory — and wires **both** producers to it behind opt-in flags: the live
server (`serve_penn --persist`, the real point: it unblocks #307's live→replay
export) and the offline bake (`generate_penn_replay --persist`, which powers
the determinism round-trip guardrail).

## Design

### 1. The store — `backend/run_store.py` (new)

`RunStore(root)` owns everything under one directory (stdlib `sqlite3` +
`json`, zero new dependencies):

```
<root>/
  sim.db                      # runs + memories tables
  <run_id>/
    manifest.json             # mirrors the runs row's manifest
    frames.jsonl              # line N = the step-N frame dict (dict[str, AgentFrame])
```

Default root (used by both flags): `godot-generative-agents/runs/`, resolved
relative to the backend package (`Path(__file__)`-based, not the CWD).
Git-ignored (see §4). Every operation opens a short-lived
`sqlite3.connect(...)` — no long-lived connection, so the store is safe from
whatever thread the loop calls it on, and simple to read.

**Schema:**

```sql
CREATE TABLE IF NOT EXISTS runs (
  id       TEXT PRIMARY KEY,
  manifest TEXT NOT NULL,      -- JSON: the meta()-shaped manifest
  status   TEXT NOT NULL,      -- 'running' | 'finished' | 'reset'
  model    TEXT,               -- llm model name, NULL under the mock brain
  created  TEXT NOT NULL,      -- ISO-8601 UTC
  cost     REAL NOT NULL DEFAULT 0.0,
  steps    INTEGER NOT NULL DEFAULT 0
);
CREATE TABLE IF NOT EXISTS memories (
  run_id       TEXT NOT NULL,
  agent        TEXT NOT NULL,
  record_id    INTEGER NOT NULL,   -- the engine MemoryRecord.id (monotonic per agent)
  kind         TEXT NOT NULL,
  importance   REAL NOT NULL,
  created_turn INTEGER NOT NULL,
  text         TEXT NOT NULL,
  embedding    BLOB,               -- little-endian float32s, NULL when absent
  extra        TEXT NOT NULL,      -- JSON: the rest of to_primitive() (last_accessed_turn,
                                   -- actor, source_event_ids, tags, metadata)
  PRIMARY KEY (run_id, agent, record_id)
);
```

Scoring/projection fields are real columns; full fidelity rides in `extra`,
so a stored record rehydrates losslessly via `MemoryRecord.from_primitive`.

**API** (exact signatures):

- `create_run(manifest: dict, run_id: str | None = None) -> str` — id defaults
  to `run-<UTCyyyymmdd-hhmmss>-<6 hex>`; writes the row (`status="running"`,
  `model` from `manifest["llm"]["model"]` when present), the run dir, and
  `manifest.json`. Rejects an existing id.
- `get_run(run_id) -> dict | None` / `list_runs() -> list[dict]` (newest
  first) — row dicts with `manifest` parsed back to a dict.
- `update_run(run_id, *, status: str | None = None, cost: float | None = None,
  steps: int | None = None) -> None` — partial update; unknown id raises.
- `append_frame(run_id, step: int, frame: dict) -> None` — validates the frame
  against the #305 contract (`dict[str, AgentFrame]` via `contract_models`)
  and requires `step` == the current line count (no gaps, no dupes — line N
  IS step N, which keeps #307's `frames[]` a straight file read); appends one
  compact JSON line, opened per call so a crash loses at most the in-flight
  line.
- `read_frames(run_id) -> list[dict]` — the lines, in order.
- `record_memories(run_id, agent: str, records: list[dict]) -> None` — each
  record is an engine `MemoryRecord.to_primitive()` dict; splits into
  columns + packed embedding (`struct.pack("<%df" % len)`) + `extra` JSON.
  `INSERT OR IGNORE` so re-sending an already-persisted record id is a no-op.
- `last_memory_id(run_id, agent) -> int` — max persisted `record_id`, `-1`
  when none (the incremental-sync cursor).
- `memories_for(run_id, agent, *, kind: str | None = None,
  since_turn: int | None = None, limit: int | None = None) -> list[dict]` —
  the lean 4-field wire projection in `record_id` order (what #307's
  `memory_streams` and the future #306 endpoints read).
- `query_memories(run_id, agent, query: str, turn: int, *,
  retrieval: RetrievalConfig | None = None, embedding_client=None)
  -> list[dict]` — rehydrates the agent's rows via
  `MemoryRecord.from_primitive`, loads them into a throwaway `AgentMemory`
  (with the optional `embedding_client`), and delegates to
  `retrieve(query, turn, **knobs, touch=False)` — the scoring stays defined
  in exactly one place; returns lean projections of the top-k.

### 2. Live wiring — `PennStepper`, not the generic loop

`PennStepper.__init__` gains `run_store: RunStore | None = None` (default
None — nothing changes for existing callers). With a store:

- `_build()` creates a run: manifest = `meta()`; each `reset()` first marks
  the old run `status="reset"`, then creates a fresh run id (a reset is a new
  world — the old frames stay readable).
- `tick()` — after a successful step: `append_frame(run_id, step, frame)`;
  per agent, `memory_stream` sync: engine records with
  `id > last-synced-id` (tracked in-process per agent, seeded from
  `last_memory_id` at run creation) go to `record_memories` as full
  `to_primitive()` dicts; `update_run(cost=ledger.total_cost_usd(),
  steps=step+1)`. End-of-day (`tick()` returning `None` in non-endless mode)
  marks `status="finished"`.
- `serve_penn` gains `--persist` (`argparse.BooleanOptionalAction`, default
  `False` — the `--cognition-tools` idiom): constructs
  `RunStore(DEFAULT_RUNS_DIR)` and hands it to the stepper; the startup
  banner prints the run id + store path when on.

`live.py` and `api.py` are untouched — the viewer and the event feed see no
difference.

### 3. Bake wiring + the determinism guardrail

`simulate()` gains an `out_memory_records: dict | None = None` out-param
beside the existing `out_memories` (backwards-compatible, backend file):
filled at the same point (`run_simulation.py:501-504`) with
`{name: [record.to_primitive() for record in agent.memory.records]}` — the
full engine records the store needs (the lean `out_memories` shape has no
`record_id` and cannot rehydrate).

`generate_penn_replay.py` gains `--persist` (same idiom, default off): after
`simulate(..., out_memory_records=...)`, create a run (manifest = the
replay's `meta`), append every frame, `record_memories` each persona's full
stream, mark `finished` with the final cost/steps.

Guardrail tests: a persisted bake's `read_frames()` == the replay file's
`frames`; `memories_for()` == its `memory_streams` projection; and
`query_memories(...)` returns the same top-k texts as the in-memory
`AgentMemory.retrieve(touch=False)` on the same stream.

### 4. Artifacts + docs

- `.gitignore`: add `godot-generative-agents/runs/`.
- `backend/README.md`: a short RunStore section (layout, the two flags, the
  #306/#307 hooks it enables); update the two forward-looking passages that
  sketched it to point at the real module.

### 5. Out of scope

- Run lifecycle/resume endpoints, run-scoped API routes, "current run"
  selection (#306). No `api.py`/`live.py` changes at all.
- The live→replay exporter and its CLI/endpoint (#307).
- Any engine change (`text_adventure_games/` untouched) — the store consumes
  `to_primitive()`/`from_primitive`/`retrieve` as-is.
- Vector DBs / Postgres; embedding *generation* (records carry embeddings
  only if the run already had an `EmbeddingClient`).
- Resuming a run in-process after a restart (needs #306; a new process on the
  same store simply creates new runs beside the old ones).
