# Interior tile art — credits & license

The Williams Hall interior cutaway is painted with the **Fantasy RPG Interior
pack by Franuka** (v2.2). The `1x` (16×16) sheets are vendored here as:

| File in this repo        | Source sheet (Franuka `1x/`)                 |
| ------------------------ | -------------------------------------------- |
| `interior_franuka.png`   | `Fantasy RPG Interior Pack (16x16 grid).png` |
| `interior_school.png`    | `Expansion_School.png`                       |
| `interior_bath.png`      | `Expansion_Bath.png`                         |

**Artist:** Franuka — https://franuka.itch.io/ — https://twitter.com/franuka_art

**License (from the pack's "License and details.txt"):** usable in commercial and
non-commercial projects; a link back to the artist's itch.io / Twitter is
requested (provided above). The pack may be edited but **not redistributed as-is
or resold**. These files are included only as game assets for this project, the
same way `Cute_Fantasy_Free/` (Kenmi) already is.

The interior is generated by `godot-generative-agents/tools/geo/furnish_building.py`, which opens the roof
of Williams Hall on `upenn_core_urban.tmj` and paints a furnished floor plan from
these sheets. See that script's header for the run order.
